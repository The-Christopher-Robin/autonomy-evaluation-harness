\begin{abstract}
This project builds a reproducible evaluation harness for AI-based autonomous platforms to systematically compare multiple red-team attacks against multiple blue-team defenses under identical mission conditions. The framework supports parameterized attack injection (e.g., GPS drift, sensor noise, timing faults, waypoint tampering), a plug-in interface for defenses (runtime monitors, IDS modules, rule-based checks), synchronized logging, and automated metrics including detection rate, false positives, detection latency, and mission impact (trajectory deviation, crash, completion delay). The result is a containerized, reusable repository and dataset outputs enabling future students to evaluate new detectors without rebuilding the simulation environment.
\end{abstract}
